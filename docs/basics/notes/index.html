Note properties

Note.get

get(noteName: string) => Note

Given a note name, it returns an object with the following properties:

  • name: the note name
  • pc: the pitch class name
  • letter: the note letter
  • step: the letter number (0..6)
  • acc: the note accidentals
  • alt: the accidental number (..., -1 = 'b', 0 = '', 1 = '#', ...)
  • oct: the octave (or null if not present)
  • chroma: the note chroma (0..11)
  • height: a number to compare and sort notes by pitch. Equals the midi number when the note has an octave (even outside the 0..127 midi range). Pitch classes get a large negative value, so they sort before any note with octave
  • midi: the note midi or null if octave is not present
  • freq: the note frequency in Hertzes, or null if the octave is not present

Register

Note.fold

fold(notes: string[], range: [low: string, high: string], options?: { each?: boolean }) => string[]

Move notes by octaves into a range of notes (both ends included), keeping their spelling. By default the whole figure moves together, so it keeps its shape: it moves by the fewest octaves that put every note in the range, and doesn't move if it's already there:

With each: true, each note moves on its own by the fewest octaves that put it in the range:

The rules at the edges:

  • A figure that doesn't fit in the range at any octave has its lowest note put in the lowest octave at or above low: Note.fold(["C2", "E4"], ["E2", "G3"]) is ["C3", "E5"].
  • In a range under an octave, a note may have no octave inside it: with each: true it goes to the octave nearest the range, and a tie goes up.
  • To keep the shape where it fits and fix only the notes at the edges, fold the whole figure first and then each note: Note.fold(Note.fold(notes, range), range, { each: true }).

A pitch class (a note without octave) has no octave to keep, so it goes on its own to the lowest octave at or above low (or, in a range under an octave, to the octave nearest the range), whatever the mode. It places notes in a register:

It returns [] if the notes are empty or one isn't a note, or if the range isn't two notes with octave from low to high. (This fold moves notes into a register; it isn't the fold of functional programming, which is reduce.)

Note.nearest

nearest(note: string, reference: string, options?: { direction?: "nearest" | "up" | "down", range?: [low: string, high: string] }) => string

Place a note near another: the octave of a note (or pitch class) nearest a reference note, keeping its spelling. For a line built one note at a time, where each note goes near the one before:

With direction: "up" or "down" it's the nearest strictly above or below, so the reference's own pitch class goes an octave away:

With a range the result is in it (both ends included). When the direction has no octave in the range, the nearest octave in the range is used, so a line turns around at the edges; when the range has no octave of the note at all, the result is "":
