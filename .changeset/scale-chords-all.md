`Scale.chords(scale, { all: true, types, order })`: every chord type whose notes are in the scale, rooted on each degree, common ones first (by `complexity`, or the dictionary's order), for any scale with a tonic. The notes are spelled as in the chord (D F# A in the diminished scale, which has Gb).
